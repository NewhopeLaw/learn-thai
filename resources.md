# Learning resources

Useful free tools to go alongside these lessons:

- **[thai-language.com](http://www.thai-language.com/)** — dictionary with audio, tone classes, and example sentences.
- **[Google Translate](https://translate.google.com/?sl=th&tl=en)** — handy for hearing Thai text spoken aloud (check spellings elsewhere).
- **Anki** flashcards — make a deck of the consonants (letter → name + class) and review daily.
- **Thai keyboard** — enable the Thai (Kedmanee) keyboard on your phone or computer so you can type what you learn.

Know a great resource? Open a pull request to add it.
