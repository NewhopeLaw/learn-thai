# Contributing

Corrections and new lessons are welcome — open an issue or a pull request.

## Conventions

- **Audience:** English-speaking beginners. Keep explanations short and concrete.
- **Thai text:** wrap it in `<span class="thai">…</span>` so it renders in a larger Thai font.
- **Romanization:** follow the system in [Lesson 1](lessons/01-how-thai-works.md):
  - `k t p` unaspirated, `kh th ph` aspirated, `j` for จ
  - doubled vowels are long (`aa`, `ii`); `ue`, `ɔ`, `ɛ`, `oe` for vowels with no English letter
  - tones: unmarked = mid, `à` low, `â` falling, `á` high, `ǎ` rising
- **Every lesson ends with an exercise**, with answers inside a `<details>` block.
- **Accuracy:** if you're not a native speaker, mention it in your PR so a native speaker can review.
