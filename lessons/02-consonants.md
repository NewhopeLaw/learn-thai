# Lesson 2: Consonants <span class="thai">พยัญชนะ</span>

Every Thai consonant has a **name**: its sound plus a "key word", the way English children say "A is for apple". For example <span class="thai">ก</span> is called <span class="thai">ก ไก่</span> *kɔɔ kài* — "k as in chicken".

Each consonant also belongs to one of **three classes** — middle, high, or low. The class doesn't change the consonant's sound, but it's essential for working out **tone** (Lesson 4). Learn each letter together with its class.

The **initial sound** column is how the letter sounds at the start of a syllable. Many letters sound different at the end of a syllable (see the bottom of this page).

## Final consonant sounds

At the end of a syllable, Thai only allows a few sounds. Every consonant collapses into one of these:

| Final sound | Common letters |
|-------------|----------------|
| -k | ก ข ค ฆ |
| -t | ด ต ท ธ ถ ส ศ ษ จ ช ซ (and others) |
| -p | บ ป พ ฟ ภ |
| -m | ม |
| -n | น ณ ญ ร ล ฬ |
| -ng | ง |
| -i / -w (vowel glides) | ย / ว |

Final -k, -t, -p are **unreleased**: your mouth closes but no air pops out.

## What to learn first

Don't memorize all 44 at once. Start with these ~20 frequent letters and add the rest gradually:

<span class="thai">ก ข ค ง จ ช ด ต ท น บ ป พ ม ย ร ล ว ส ห อ</span>
