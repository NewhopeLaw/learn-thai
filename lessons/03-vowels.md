# Lesson 3: Vowels <span class="thai">สระ</span>

Thai vowels are written **around** the consonant: before, after, above, below, or a combination. Below, **อ** is used as a placeholder for "any consonant" — it shows where the vowel goes.

Most vowels come in **short/long pairs**. Length changes meaning, so hold long vowels about twice as long.

## Short and long pairs

| Short | Long | Sound | Example |
|-------|------|-------|---------|
| <span class="thai">อะ</span> a | <span class="thai">อา</span> aa | *a* in "father" | <span class="thai">มา</span> maa — come |
| <span class="thai">อิ</span> i | <span class="thai">อี</span> ii | *ee* in "see" | <span class="thai">ดี</span> dii — good |
| <span class="thai">อึ</span> ue | <span class="thai">อือ</span> uue | *oo* with spread lips | <span class="thai">มือ</span> muue — hand |
| <span class="thai">อุ</span> u | <span class="thai">อู</span> uu | *oo* in "food" | <span class="thai">ดู</span> duu — look |
| <span class="thai">เอะ</span> e | <span class="thai">เอ</span> ee | *e* in "they" | <span class="thai">เท</span> thee — pour |
| <span class="thai">แอะ</span> ɛ | <span class="thai">แอ</span> ɛɛ | *a* in "cat" | <span class="thai">แม่</span> mɛ̂ɛ — mother |
| <span class="thai">โอะ</span> o | <span class="thai">โอ</span> oo | *o* in "go" (no glide) | <span class="thai">โต</span> too — big |
| <span class="thai">เอาะ</span> ɔ | <span class="thai">ออ</span> ɔɔ | *aw* in "law" | <span class="thai">พ่อ</span> phɔ̂ɔ — father |
| <span class="thai">เออะ</span> oe | <span class="thai">เออ</span> ooe | *u* in "fur" | <span class="thai">เจอ</span> joe — meet |
| <span class="thai">เอียะ</span> ia | <span class="thai">เอีย</span> iia | *ee-a* | <span class="thai">เมีย</span> mia — wife |
| <span class="thai">เอือะ</span> uea | <span class="thai">เอือ</span> uuea | *ue-a* | <span class="thai">เรือ</span> ruea — boat |
| <span class="thai">อัวะ</span> ua | <span class="thai">อัว</span> uua | *oo-a* | <span class="thai">วัว</span> wua — cow |

## Special vowels

| Vowel | Sound | Example |
|-------|-------|---------|
| <span class="thai">อำ</span> | am | <span class="thai">น้ำ</span> náam — water |
| <span class="thai">ไอ</span> / <span class="thai">ใอ</span> | ai (both identical in sound) | <span class="thai">ไป</span> pai — go; <span class="thai">ใจ</span> jai — heart |
| <span class="thai">เอา</span> | ao | <span class="thai">เขา</span> khǎo — he/she |

## Spelling changes to watch for

- **Short vowel + final consonant:** <span class="thai">อะ</span> becomes <span class="thai">อั</span>: <span class="thai">กัน</span> kan (together).
- **Short เอะ / แอะ + final:** the <span class="thai">ะ</span> becomes <span class="thai">็</span>: <span class="thai">เด็ก</span> dèk (child).
- **Hidden vowels:** some syllables have no written vowel. A lone consonant between two others usually takes **o**: <span class="thai">คน</span> khon (person).
- **อ as a vowel carrier:** a word that starts with a vowel sound is written on <span class="thai">อ</span>, which is silent: <span class="thai">อาหาร</span> aa-hǎan (food).
