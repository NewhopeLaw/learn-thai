# Lesson 5: Greetings & survival phrases

## Polite particles: ครับ / ค่ะ

Thai speakers end most sentences with a polite particle. It depends on **the speaker's** gender:

| Speaker | Particle | Use |
|---------|----------|-----|
| Male | <span class="thai">ครับ</span> khráp | statements and questions |
| Female | <span class="thai">ค่ะ</span> khâ | statements |
| Female | <span class="thai">คะ</span> khá | questions |

Add it to everything below. It's the single easiest way to sound polite.

## Greetings

| Thai | Romanization | Meaning |
|------|--------------|---------|
| <span class="thai">สวัสดี</span> | sa-wàt-dii | hello / goodbye |
| <span class="thai">สบายดีไหม</span> | sa-baai dii mǎi | how are you? |
| <span class="thai">สบายดี</span> | sa-baai dii | I'm fine |
| <span class="thai">คุณชื่ออะไร</span> | khun chûue a-rai | what's your name? |
| <span class="thai">ผมชื่อ...</span> | phǒm chûue... | my name is... (male) |
| <span class="thai">ฉันชื่อ...</span> | chǎn chûue... | my name is... (female) |
| <span class="thai">ยินดีที่ได้รู้จัก</span> | yin-dii thîi dâi rúu-jàk | nice to meet you |
| <span class="thai">ลาก่อน</span> | laa-kɔ̀ɔn | goodbye (more final) |

## Essentials

| Thai | Romanization | Meaning |
|------|--------------|---------|
| <span class="thai">ขอบคุณ</span> | khɔ̀ɔp-khun | thank you |
| <span class="thai">ขอโทษ</span> | khɔ̌ɔ-thôot | sorry / excuse me |
| <span class="thai">ไม่เป็นไร</span> | mâi pen rai | no problem / never mind |
| <span class="thai">ใช่</span> | châi | yes / that's right |
| <span class="thai">ไม่ใช่</span> | mâi châi | no / that's not right |

## Getting around

| Thai | Romanization | Meaning |
|------|--------------|---------|
| <span class="thai">...อยู่ที่ไหน</span> | ... yùu thîi-nǎi | where is ...? |
| <span class="thai">ห้องน้ำอยู่ที่ไหน</span> | hɔ̂ng-náam yùu thîi-nǎi | where's the toilet? |
| <span class="thai">เท่าไร</span> | thâo-rài | how much? |
| <span class="thai">แพงไป</span> | phɛɛng pai | too expensive |
| <span class="thai">ลดได้ไหม</span> | lót dâai mǎi | can you lower the price? |

## Mini dialogue

> **A:** <span class="thai">สวัสดีครับ สบายดีไหมครับ</span>
> *sa-wàt-dii khráp, sa-baai dii mǎi khráp* — Hello, how are you?
>
> **B:** <span class="thai">สบายดีค่ะ ขอบคุณค่ะ</span>
> *sa-baai dii khâ, khɔ̀ɔp-khun khâ* — I'm fine, thank you.

## Exercise

Role-play with a friend (or out loud alone): greet someone, introduce yourself, and ask where the toilet is. Remember your particle!
