# Lesson 6: Numbers <span class="thai">ตัวเลข</span>

Thai has its own digits, but everyday life (prices, phone numbers) mostly uses Arabic digits. Learn to recognize both.

## 0–10

| Digit | Thai digit | Word | Romanization |
|-------|------------|------|--------------|
| 0 | <span class="thai">๐</span> | <span class="thai">ศูนย์</span> | sǔun |
| 1 | <span class="thai">๑</span> | <span class="thai">หนึ่ง</span> | nùeng |
| 2 | <span class="thai">๒</span> | <span class="thai">สอง</span> | sɔ̌ɔng |
| 3 | <span class="thai">๓</span> | <span class="thai">สาม</span> | sǎam |
| 4 | <span class="thai">๔</span> | <span class="thai">สี่</span> | sìi |
| 5 | <span class="thai">๕</span> | <span class="thai">ห้า</span> | hâa |
| 6 | <span class="thai">๖</span> | <span class="thai">หก</span> | hòk |
| 7 | <span class="thai">๗</span> | <span class="thai">เจ็ด</span> | jèt |
| 8 | <span class="thai">๘</span> | <span class="thai">แปด</span> | pɛ̀ɛt |
| 9 | <span class="thai">๙</span> | <span class="thai">เก้า</span> | kâao |
| 10 | <span class="thai">๑๐</span> | <span class="thai">สิบ</span> | sìp |

## Building bigger numbers

Thai numbers are very regular. Two special cases:

- **"one" at the end of 11, 21, 31… is <span class="thai">เอ็ด</span> èt**, not หนึ่ง.
- **20 is <span class="thai">ยี่สิบ</span> yîi-sìp**, not "two-ten".

| Number | Thai | Romanization |
|--------|------|--------------|
| 11 | <span class="thai">สิบเอ็ด</span> | sìp-èt |
| 12 | <span class="thai">สิบสอง</span> | sìp-sɔ̌ɔng |
| 20 | <span class="thai">ยี่สิบ</span> | yîi-sìp |
| 21 | <span class="thai">ยี่สิบเอ็ด</span> | yîi-sìp-èt |
| 30 | <span class="thai">สามสิบ</span> | sǎam-sìp |
| 45 | <span class="thai">สี่สิบห้า</span> | sìi-sìp-hâa |
| 100 | <span class="thai">หนึ่งร้อย</span> | nùeng-rɔ́ɔi |
| 1,000 | <span class="thai">หนึ่งพัน</span> | nùeng-phan |
| 10,000 | <span class="thai">หนึ่งหมื่น</span> | nùeng-mùuen |
| 100,000 | <span class="thai">หนึ่งแสน</span> | nùeng-sɛ̌ɛn |
| 1,000,000 | <span class="thai">หนึ่งล้าน</span> | nùeng-láan |

Note that Thai has its own words for **ten thousand** and **hundred thousand**.

## Money

The currency is the baht, <span class="thai">บาท</span> bàat.

| Thai | Romanization | Meaning |
|------|--------------|---------|
| <span class="thai">ห้าสิบบาท</span> | hâa-sìp bàat | 50 baht |
| <span class="thai">สองร้อยบาท</span> | sɔ̌ɔng-rɔ́ɔi bàat | 200 baht |
| <span class="thai">อันนี้เท่าไร</span> | an-níi thâo-rài | how much is this? |

## Exercise

Say these numbers in Thai: **7, 15, 21, 38, 99, 250, 1,500**

<details markdown="1">
<summary>Answers</summary>

- 7 — jèt
- 15 — sìp-hâa
- 21 — yîi-sìp-èt
- 38 — sǎam-sìp-pɛ̀ɛt
- 99 — kâao-sìp-kâao
- 250 — sɔ̌ɔng-rɔ́ɔi-hâa-sìp
- 1,500 — nùeng-phan-hâa-rɔ́ɔi
</details>
