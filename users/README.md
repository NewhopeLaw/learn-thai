# Learner folders

Each learner's progress lives here as `<name>.json`, the same name as their personal link
(`newhopelaw.github.io/learn-thai/<name>`). The app reads it automatically when that link is opened.

To update it by hand: in the app, More → **Back up now** downloads `<name>.json`; upload it here with
**Add file → Upload files** and commit. With a GitHub key connected under More, the app uploads it itself.
